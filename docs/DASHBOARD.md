# 两轮研究的只读浏览器

浏览器把真实智能体记录、独立测试、失败案例和校准结果放在同一界面。仅查看保存的文件，不调用模型、求解器或上传接口，也不修改研究状态。需要 Python 3.10 或更新版本；本界面仅使用 Python 标准库，无需安装数值依赖、JavaScript 包或 CDN。

## 启动

在项目根目录执行：

```text
python dashboard_revision.py --port 8766
```

打开 <http://127.0.0.1:8766>。如使用已有虚拟环境，将 `python` 换成该环境的解释器即可。也可明确指定项目根目录：

```text
python dashboard_revision.py --root /path/to/CrowdLocateLab --port 8766
```

Windows PowerShell 可使用：

```powershell
.\Start-Dashboard.ps1 -Port 8766
```

若当前 PowerShell 策略不允许运行脚本，直接执行上面的 Python 命令；启动器不会更改策略。macOS / Linux 可执行 `sh Start-Dashboard.sh 8766`。两个启动脚本均不安装依赖、不登录账号、不固定机器上的 Python 路径。

终端需保持打开；按 Ctrl+C 关闭服务。关闭界面不会停止另一终端中的科研智能体。服务仅监听本机 `127.0.0.1`，端口被占用时可改为另一个端口。

## 版本和状态

右上角切换两个独立版本：

| 版本 | 研究记录 | 独立测试 |
| --- | --- | --- |
| 第一轮 · V2 | `runs/live_reference/` | `results/benchmark/` |
| 第二轮 · Revision | `runs/revision_reference/` | `results/revision_benchmark/` |

默认打开第二轮。不存在的研究显示等待，不用第一轮数据填补；运行中的评测在写入完整 JSON 之前显示等待。界面每 8 秒刷新研究状态、时间线、校准和边界结果；失败案例页可按“刷新”重新加载已生成案例。LIVE 标签依据保存的真实 provider 身份，REPLAY 明确表示读取历史决策，不能当成新模型推理。

## 五个页面

**研究概览**显示实际动作、模型请求、批评记录和冻结后测试。查看方法注册时的假设、配置和数学定义，再看冻结结论。缺失的模型名称或 token 用量保留“未报告”，不推测为某个模型或零消耗。对照表保留较差结果；总体改善不等于各场景不劣化。

**智能体迭代**保留真实模型摘要、预期观察、工具参数与返回、失败和审阅。默认加载最近 150 条，点击“加载更早的事件”可向前阅读完整运行。用“模型决策—工具执行—独立批评”筛选跟踪一次修订；展开的文字来自保存记录，不是界面生成的叙事。公开决策摘要不等于模型私有思维链。

**失败案例**可按集合、场景、方法筛选，按该方法的误差升降序排列，或用 case_id 的任意片段搜索。选择一个案例后，界面显示同一输入上保存的全部方法结果，避免只挑一个有利对照。

- 三角形：带测量误差的上报锚点；小数字为观测索引。
- ×：参考时刻的位置真值；仅供离线评测计分和结果展示，不作为定位求解器或模型规划器的观测输入。
- 圆点：不同方法的估计位置；当前排序方法以较大圆点标出。
- 速度箭头：保存速度向量对应的 5 秒位移，方便在同一长度尺度上观察。
- 历史测距圆：默认隐藏。勾选后可用滑杆显示全部或逐个圆，旁边显示相应观测时间。不同圆属于不同历史时刻，运动目标下不应期待它们都交于当前点。

图的坐标范围以锚点、估计点和速度端点适配；大半径圆超出视野的部分裁切，避免整张图被一个异常距离压缩。显示或隐藏真值、圆和速度只改变浏览器绘图，不改变指标和案例。图下有方法误差、速度、工作量及完整 CV / Jacobian 等诊断。

V2 的案例页还读取 `results/sensitivity/`，可检索原第一轮的极端失败，例如 `921984553727470929` 对应约 64 m 的失败。该案例在第二轮仍只是历史背景，不冒充第二轮独立测试。

**校准与拒绝**并列显示 Global 与 Mondrian 的实际记录，包括覆盖率、半径、分场景、分组和拒绝曲线。V2 没有 Mondrian 时会明确提示。`infinity` 显示为 ∞，并保留相关原始诊断；无限半径不是可用的高精度输出。边际覆盖、组内覆盖、拒绝子集和分布偏移条件不同，不能相互替代。

**6–12 份观测边界**仅从第二轮 `edge` 逐例结果汇总，按场景切换均值、CEP90、运动选择比例和 CV 可用比例；勾选方法控制曲线数量。缺失的观测数不补点，缺少 CV 的固定方法不被当成 CV 可用率为零。第一轮没有独立 edge 数据时保持空白，其 n=8 证据仍可在敏感性案例中查看。

## 证据与只读范围

界面读取固定目录下的状态、事件、冻结摘要、已保存的主测试 / 压力 / 边界输入与逐例预测，以及校准结果。不会提供任意文件下载、目录浏览、shell 命令、外部模型调用、上传或写入接口。版本参数只能为 `v2` / `v3`，案例 key 只能查找已载入的结果，不作为文件路径执行。页面使用本地 Canvas 和标准浏览器 API，不请求外部脚本或字体。

这是一种审阅方式，不替代原始证据哈希校验或论文中的统计论证。多个方法得到完全相同的结果可能是去重后共享计算，需结合正式 protocol 中的 aliases / 配置解释，不把这些行当成独立重复试验。

软件检查命令：

```text
python -m unittest discover -s tests -p test_revision_dashboard.py -v
```

测试使用明确的临时夹具，只检查数据读取、缺失处理、配对案例、统计汇总和只读 HTTP 接口，不运行任何研究或留出数据。课堂展示建议见 [一页答辩路径](DEFENSE_DEMO.md)。
