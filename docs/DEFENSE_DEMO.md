# 一页答辩演示路径（约 7 分钟）

先运行 `python dashboard_revision.py --port 8766`，打开本地浏览器。演示使用已保存的真实运行证据；开场明确“这是研究过程与结果的审阅，不是把历史回放冒充现场推理”。

| 时间 | 页面与动作 | 讲述要点 |
| --- | --- | --- |
| 0:00–0:45 | 研究概览，说明原题与合成子问题 | 原工业题缺少完整真实数据及验收口径；项目研究异步污染定位，不声称解决完整开放问题。 |
| 0:45–2:00 | 第二轮“智能体迭代”，选一条模型动作并展开相邻工具返回 | 模型实际决定下一步、提出假设和选择工具；数值程序执行计算。展示请求、动作、观察的对应关系，而不只展示聊天结论。 |
| 2:00–3:00 | 切到批评筛选，再定位其后的修订、消融或验证动作 | 说明哪条反馈改变了研究方向。若某项假设被拒绝或工具失败，保留并解释；批评角色独立不等于换了另一模型。 |
| 3:00–4:00 | 切第一轮，失败案例搜索 `921984553727470929` | 展示约 64 m 的大误差、基线对照和“求解成功 / 满秩”诊断；勾选历史测距圆，逐个切换。强调模型诊断正常不能证明位置正确。 |
| 4:00–5:00 | 切第二轮，打开“6–12 份观测边界” | 比较少量观测时误差和 CV 可用比例，指出门控结构与观测证据的区别。结果未完成就展示等待状态，不补造改善曲线。 |
| 5:00–6:00 | 校准与拒绝，Global / Mondrian 对照 | 同时讲覆盖与半径；指出分组、拒绝后子集、分布偏移的条件。若出现无限半径或覆盖不足，应直接说明限制。 |
| 6:00–7:00 | 回概览及第二轮失败案例，展开冻结结论 | 说明哪些结论得到支持、哪些场景仍失败；两轮方法各自被冻结，测试没有被用来悄悄替换第一轮配置。结束时给出代码、PDF、记录和复现入口。 |

优先选择日志中真实存在、证据链完整的一次修订。第二轮若仍在运行，可展示已完成的动作与明确的等待状态，不能把预期结果当作实测结果。按误差降序展示失败，不只挑选最成功的案例。

可准备的三个回答：

1. **智能体比普通脚本多做了什么？** 用实际模型动作、工具返回及下一次改变的假设回答；不把预实现数学算子说成模型的新发明。
2. **为什么还展示不如基线的结果？** 科研要求识别方法适用范围；这些结果正是修订的动机和结论强度的边界。
3. **图中的真值从哪里来？** 合成评测生成器保留真值供离线计分，定位输入只有观测；真实应用入口没有真值可用。
