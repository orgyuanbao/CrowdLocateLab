## 1. 符号推导的审查结论

前提仍是二维恒速、精确锚点/时刻、确定性硬界 epsilon≥0。诊断器的实际观测域为 y≥0，
并非历史 sigma 的概率解释。所有平方判据只在 q,r≥0、epsilon≥0 及各自明示前提内使用。

|审查目标|推导复核及尝试推翻的边界|结论|
|---|---|---|
|量词|实际 y 固定：存在两可行轨迹且当前位置不同。共同模式：对指定候选对存在同一个 y。逐行观测不附加耦合约束，故逐行中点能组成共同向量。距离 1、3，epsilon=1：共同 y=2 成立，实际 y=1 的该对不成立。|没有混用量词；单候选遗漏镜像仍只输出未找到见证。|
|实际数据平方判据|从 y-e≤sqrt(q)≤y+e 出发；下界须裁为 max(0,y-e)。因 y,e≥0，上下界非负，平方等价。零下界及上下壳边界均审查。|v1 与 v2 判据正确；负 y 不在该程序域内。|
|共同观测平方判据|区间相交等价于 abs(sqrt(q)-sqrt(r))≤2e。第一次平方得 S=q+r-4e²≤2sqrt(qr)。S≤0 自动成立；S>0 时两侧非负才能再次平方。|正确；不能删去 S≤0 分支。q=r=0、q=r 非平方数、单边零距离均覆盖。|
|反射|S_L(p)=p-2n[n·(p-c)] 为仿射等距映射，速度只作线性反射。正交分解给 q=r_tan²+(s-h)²，q'=r_tan²+(s+h)²，差为 4hs。|平移项不能错误地加在速度上；v1 没有此错误。|
|零距离|q+q'=0 强制 r_tan=s=h=0，delta=0；只有一个距离为零时分母仍正。|不能在双零处用 0/0；精确平方检查本身无需除法。|

## 2. 独立实现的有限核验

`oracle_math_v2.py` 不导入任何 diagnostic，也不调用其谓词生成期望答案：

- 有理平方根：用分子/分母整数平方根直接判定是否为有理数；可精确处理阈值相等。
- 非平方数：另建有理闭区间 [floor(sqrt(q)·2^b)/2^b, 上端]，b=16 至 1024，
  对距离与原始允许观测区间直接比较；不使用 S²≤4qr 的公式作 oracle。
  固定模式比较根区间和 [y-e,y+e]，共同模式比较两个允许观测区间的交集。
  预算耗尽会报错，绝不默认为真或假。本次没有耗尽。
- q≠r 时，如果两根差为非零有理数 c，则 sqrt(r)=(q-r-c²)/(2c) 必为有理数。
  因而 oracle 对有理根及 q=r 的相等情形单独处理后，剩余有限样例可用区间分离。
- 四阶行列式用 24 项排列展开，区别于 v1 的高斯消元。

## 3. CLI 缺陷、安全复现与工程修复

所有复现仅修改本单元新建的 `checks_*_v2/` 文件，保留了三个执行轮次的临时目录；
从未将原 v1 数据作为覆盖目标。每次 CLI 的完整 argv、stdout、stderr、退出码在对应结果 JSON 的 `commands` 中。

|确认的问题|v1 的实际复现|v2 回归结果与实现|
|---|---|---|
|重复 JSON 键静默替换|先写 y=[2]，再写 y=[1]，退出 0 且采用后者输出 no_witness_found|退出 2、invalid_input；object_pairs_hook 对任意对象拒绝重复键，也检查了转义键 `\u0079`|
|输出路径等于输入|新建 input_equals_output_v2.json 被 v1 改写成结果|v2 退出 2、invalid_output，输入逐字节不变|
|覆盖早先结果|v1 把新建的 previous result 标记覆盖|v2 退出 2，原结果逐字节不变；首次写入新证书成功，第二次拒绝|
|无资源上限|v1 接受 33 观测、17 候选、超过字节上限的文件及 1e25|v2 拒绝；只做这些温和反例，没有运行耗尽资源的大输入|

新 `diagnostic_v2.py` 的数学检查核心保持原样；变更属于**工程修复**：

|上限|精确策略|
|---|---|
|输入文件|最多 32768 字节；读取最多上限+1 字节再拒绝。恰好 32768 字节的有效 JSON 已接受|
|维度|1–32 观测，1–16 候选；平方距离前检查。32/16 接受，33 或 17 拒绝|
|数值字面值|最多 64 字符，ASCII 十进制/科学记数或整数分数；科学记数指数绝对值≤24，在 Fraction 转换前检查|
|精确输入值|绝对值≤10^6，约分后分子绝对值和分母均≤10^24；全部条件同时满足|
|结构|JSON 嵌套深度≤8；拒绝重复键、未知字段及非有限数。Python API 也检查维度及数值界|
|输出|必须为不同于输入的新路径；预检之后以文件模式 x 排他创建，即使检查后出现同名文件也不会截断它|

最多 120 对、每对最多 32 行，且输入有理数位数有限；这限制了本工具的有理运算规模，
不声称形式化证明了任意平台的墙钟时间上界。超界返回 invalid_input，是工程域限制，不是关于数学唯一性的结论。
新输出不可覆盖，错误输出同样只允许写入新路径；父目录不存在则报告 invalid_output。
排他创建不保证磁盘故障时新文件写入完整，但保证不会因此覆盖旧文件。

回归还覆盖：65 字符、过大分子/分母、过大数值、巨大指数、负 epsilon、NaN 字符串/JSON 常量、
分母为零、过深嵌套、未知字段、混用量词、布尔时刻、非法 UTF-8、缺失输入、输出父目录缺失。
64 字符、分母恰为 10^24、1e-24、绝对值恰为 10^6 均有接受检查。
