**模型假设。** 二维精确已知锚点 a_i、精确已知时刻 t_i，恒速参数 theta=(x,v)∈R^4，
d_i(theta)=||x+t_i v-a_i||。只讨论确定性硬界 epsilon_i≥0。
它是新增建模假设，历史无界随机噪声没有自动满足该界。
下述实际观测域取 y_i≥0，允许 y_i=0 以检查零距离边界；程序将负观测作为不支持的输入拒绝。
这不是声称原题必然排除了负值，而是本版诊断器的显式输入域。
理论对任意实数时刻成立；实验只使用 t_i≤0。程序不从真值、场景标签或未来观测生成候选。
候选由调用方提供，程序不做拟合。

## 1. 定义及量词

定义实际数据的可行参数集及当前位置投影：

    F(y,epsilon)={theta: 对所有 i, |d_i(theta)-y_i|≤epsilon_i},
    X(y,epsilon)={x: 存在 v, (x,v)∈F(y,epsilon)}.

**实际数据歧义**是存在 theta_1、theta_2∈F(y,epsilon)，且 x_1≠x_2。
这里 y 已给定，不得替换。

**共同观测的最坏情形**是在固定 a,t,epsilon 下，存在一组 y≥0 和两条轨迹，
使它们对这个同一 y 都可行且当前位置不同。
对于预先指定的两条轨迹，先问“存在 y 使两者可行”；这仍不是关于某个实际 y 的断言。
本版 `common_y` 只检查输入候选对；两种模式均不遍历 R^4。

### 命题 A（已证明）：实际数据的候选对证书

若某对候选满足 x_1≠x_2 且对每行同时有

    |d_i(theta_1)-y_i|≤epsilon_i, |d_i(theta_2)-y_i|≤epsilon_i,

则实际数据有歧义。这些条件对**指定候选对**是充要的；对整个连续参数空间只是充分见证。
证明直接来自 F、X 的定义。遗漏另一分支或候选对失败，不能推出 X 单点，甚至不能推出 F 非空。
速度不同但当前位置相同不构成本题所需见证。

### 命题 B（已证明）：点估计误差下界及拒绝的含义

对 A 的同一数据 y，令 D=||x_1-x_2||>0。
任意仅依赖输入的单点估计 z，对至少一个可行世界的误差≥D/2，因为

    D≤||x_1-z||+||z-x_2||≤2 max(||x_1-z||,||x_2-z||).

它是确定性可行世界上的最坏误差下界，不是频率风险或置信概率。
对于随机输出，同一输入下输出律相同，取期望后至少一个世界的期望欧氏误差≥D/2；
并不指定每次抽样由哪个世界达到该误差。
若目标是保证每个可行世界的误差≤r，而已找到 D>2r，就有拒绝该保证的严格依据。
D=2r 只排除了严格小于 r 的保证。反过来 D≤2r 或未找到见证都不允许安全接受。
任一覆盖所有可行位置的输出集合必须包含这两个点，因此直径至少 D；若输出为圆盘，半径至少 D/2。
本单元不声称最优覆盖半径等于直径的一半。

### 命题 C（已证明）：共同观测与实际观测之间的精确差别

对某行令 d_1,d_2≥0，m=(d_1+d_2)/2，delta=|d_1-d_2|。
两个允许观测区间 [d_1-epsilon,d_1+epsilon] 与 [d_2-epsilon,d_2+epsilon]
相交当且仅当 delta≤2epsilon。若相交，m≥0 位于交集内。
逐行独立选择 m_i 即构成共同向量 y，因此

    存在共同 y≥0 使指定两条轨迹可行 ⇔ 对所有 i, delta_i≤2epsilon_i.

这是**指定轨迹对**的充要条件，对“存在任意轨迹对”并不完整。
对于实际给定的 y，有精确恒等式

    max(|d_1-y|,|d_2-y|)=|y-m|+delta/2,

因为两个距离可写成 m±delta/2。因此实际数据的条件是

    对所有 i, |y_i-m_i|+delta_i/2≤epsilon_i.

共同条件只检查区间是否相交；实际条件还要求 y 落在交集内。
若实际 y=d_1，实际条件化为 delta≤epsilon，而非 delta≤2epsilon。

**精确量词反例。** 一行 a=(0,0),t=0，静态候选 x_1=(1,0),x_2=(3,0)，epsilon=1。
距离为 1、3，共同 y=2 在边界成立。但实际 y=1 只允许第一个候选，不允许第二个。
此例仅反驳把“共同 y 存在”误当成“指定候选对解释实际 y”，不声称实际 y 的全局解唯一。

## 2. 反射、近共线与异步时刻

令参考直线 L={z:n·(z-c)=0}，||n||=1，Q=I-2nn^T。
点反射 S(z)=Qz+2n(n·c)。整条轨迹的反射仍恒速：

    x'=S(x), v'=Qv, S(x+t_i v)=x'+t_i v'.

定义目标和锚点的有符号法向坐标

    s_i=n·(x+t_i v-c), h_i=n·(a_i-c),

以及 r_i=||(I-nn^T)(x+t_i v-a_i)||。r_i 是切向差的长度，不是观测残差。
则原轨迹与反射轨迹的平方距离分别为

    d_i^2=r_i^2+(s_i-h_i)^2,
    (d'_i)^2=r_i^2+(s_i+h_i)^2.

### 命题 D（已证明）：精确距离分裂和保守条件

两式相减得到 (d'_i)^2-d_i^2=4h_i s_i。
当 d_i+d'_i>0，

    delta_i=|d'_i-d_i|=4|h_i s_i|/(d_i+d'_i).

若分母为零，两距离都为零，定义 delta_i=0，不能使用 0/0。
逆三角不等式作用于锚点与其反射给 delta_i≤2|h_i|；
作用于目标与其反射又给 delta_i≤2|s_i|。于是

    delta_i≤2 min(|h_i|,|s_i|).

反射轨迹对具有共同观测的精确条件是 delta_i≤2epsilon_i；
正分母时等价于 2|h_i s_i|≤epsilon_i(d_i+d'_i)。
实际数据还必须满足命题 C 中心偏差条件。
一个易算的共同观测充分条件是 min(|h_i|,|s_i|)≤epsilon_i 对每行成立；
特别地 |h_i|≤epsilon_i 对所有 i 成立即足够，与速度大小无关，但该保守式不是必要条件。
**不能**据此忽略实际 y 的中心偏差。
若已知第一条轨迹对实际 y 的残差，再有

    |d_i-y_i|+delta_i≤epsilon_i,

则第二条也可行；这是更保守的充分条件，不是实际双可行的必要条件。

异步影响显式体现在 s_i=s_0+t_i n·v，以及 r_i、距离分母。
例如目标在某次观测时过线 s_i=0，即使该锚点偏离 L 也有完全相同的距离。
反之，偏离很小但误差界为零且 h_i s_i≠0 的一行，就会排除这一**指定反射对**。
当前位置分歧 D=2|s_0|，故反射见证的两点误差下界为 |s_0|。
s_0=0 时即使轨迹速度不同，也没有来自这一对的当前位置歧义见证。
若所有 h_i=0，则恢复已有共线反射结论。若 epsilon 全为零，距离相等充要条件为每行 h_i s_i=0。

### 非共线且局部满秩的精确反例（本单元构造）

取 L 为水平轴，theta_1=(0,3,1,1)，theta_2=(0,-3,1,-1)，参数次序为 x_x,x_y,v_x,v_y。

| 行号（从 0 起） | t | a | y | epsilon |
|---|---:|---|---:|---:|
|0|-4|(-4,0)|1|0|
|1|-3|(-3,1)|1|0|
|2|-2|(-2,0)|1|0|
|3|-1|(-5/2,0)|5/2|0|
|4|0|(-4,0)|5|0|

三个锚点 (-4,0)、(-2,0)、(-3,1) 已非共线。
仅第 1 行 h=1，但此时 s=3+t=0；其他行 h=0。因此两条轨迹逐行平方距离完全相同，
精确值为 (1,1,1,25/4,25)。当前位置间距为 6 m，下界 3 m。

令 B_i=[z_ix,z_iy,t_i z_ix,t_i z_iy]，z_i=x+t_i v-a_i。
在 theta_1 处，每个 d_i>0，距离 Jacobian 为 diag(1/d_i)B，因此与 B 同秩。
取行 (0,1,3,4)，有理数矩阵为

    [ 0   -1    0      4 ]
    [ 0   -1    0      3 ]
    [ 3/2  2   -3/2   -2 ]
    [ 4    3    0      0 ]

其行列式为 -6≠0（也由有理消元程序复算），故 Jacobian 满列秩 4。
这个反例同时排除“锚点非共线即可全局消歧”和“某候选 Jacobian 满秩即可全局消歧”。
它不反驳静态、同步三非共线锚点的通常唯一性结论，因为这里使用未知速度和异步观测。

## 3. 完整判定与本版工具之间的界限

对本版 y≥0 域，定义 l_i=max(0,y_i-epsilon_i)，u_i=y_i+epsilon_i。
实际可行性等价于 l_i^2≤||x+t_i v-a_i||²≤u_i²。
所有数据有理时，全局当前位置歧义可写成实数上的有限多项式存在式：

    存在 theta_1,theta_2∈R^4，二者均满足所有上述平方不等式，且
    (x_1x-x_2x)^2+(x_1y-x_2y)^2>0.

该式与实际数据歧义等价。实闭域判定方法原则上能对有理系数公式完整判定；本单元没有实现它，
也没有给出其运行预算或实用性能保证。
若取消 y≥0 的程序域限制，应先检查 y_i+epsilon_i<0 的空可行情形，不能直接照搬平方上界。
候选枚举只解决存在式中有限候选点的检查；不存在从“这些候选失败”到“连续公式为假”的证明。

## 4. 可运行诊断器与精确性

`diagnostic_v1.py` 输入 JSON：`anchors` 为 n×2，`times`、`epsilon` 长 n，
`candidates` 为 k×4，至少一个候选。`fixed_y` 模式还需长度 n 的 `y`。
`common_y` 必须省略 `y`，以避免把两种问题混用。两种模式返回 `witness` 或 `no_witness_found`；
非法输入返回 `invalid_input`，CLI 退出码 2；正常诊断退出码 0。

整数、写出的有限十进制或形如 `"5/2"` 的字符串均按**该字面值的精确有理数**解释。
JSON 浮点 token 先读为字符串，再转 Fraction。Python API 对有限 float 使用其 `str` 十进制值；
不把它说成原始未舍入真实值。若输入来自此前的浮点计算，证书仅适用于送入的有理近似。
需要处理锚点/时间输入误差时，须另做误差模型，本版没有自动覆盖。

令 q=d²≥0。实际行检查 l²≤q≤u²，全为有理算术，没有浮点容差。
共同观测行检查 |sqrt(q)-sqrt(r)|≤2epsilon，精确化为

    S=q+r-4epsilon²；若 S≤0 则通过，否则要求 S²≤4qr。

证明：先平方原式得到 S≤2sqrt(qr)；仅当 S>0 时再平方，两侧非负，等价性保留。
这个条件覆盖 q=r=0 和 epsilon=0，不需要除法。
输出平方距离、候选索引、D²、D²/4 的有理数，后者即误差下界平方的精确表达。
另用整数平方根输出 sqrt(D²/4) 的有理**向下界**，不会因四舍五入夸大下界；极小分歧可能向下截成零，
此时仍保留正的精确 D²/4。共同模式输出显式代数观测构造 y_i=(sqrt(q_i)+sqrt(r_i))/2。

枚举工作量 O(n k²)，无连续优化、无全局搜索、无唯一性证书。
本版只用已给候选；没有实现自动选择参考直线或反射候选生成。
零距离时精确可行检查有效，距离 Jacobian 本身不可微，故程序不输出那里的秩证书。
