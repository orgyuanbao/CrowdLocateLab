This Skill is authored by the CrowdLocateLab integration. The referenced upstream commit contains no implementation of this Skill; the name matches the upstream controller's expected discovery path.

Read the current immutable problem and relevant materials before extending the saved research. Reuse existing research artifacts when continuing the same session.

Choose one substantial mathematical unit: formulate a testable claim, derive a result, construct a counterexample, or design and execute a bounded experiment. State the quantifiers, dimensions, rank conditions, and noise assumptions required by a claim. For localization, distinguish local Jacobian identifiability from global uniqueness and conditioning from accuracy.

For experiments, record the exact seed, data construction, estimator, metrics, and scope before interpreting results. Preserve failures and counterexamples. A finite collection of successful numerical cases does not prove a universal claim. A new definition or diagnostic is a project proposal unless its novelty has independently been established.

Save the derivation or executable experiment and actual observations under the current run directory. Explicitly label definitions, proved statements, empirical observations, conjectures, and unresolved obligations. Conclude the unit with the required upstream status JSON and a concrete next mathematical step.
